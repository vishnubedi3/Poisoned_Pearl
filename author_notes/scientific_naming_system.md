The scientific naming system for Poisoned Pearl is formalized using the State-Stoichiometric Hybrid structure. This system guarantees Layer 1 scientific accuracy by decoupling stoichiometric count from atomic oxidation states, mapping deeply eroded Roman-Prakrit roots into a rigid syntactic formula.

The Canonical Naming Sequence:

[Stoichiometric Prefix]-[Electropositive Root]-[Oxidation State in Roman Numerals] [Stoichiometric Prefix]-[Electronegative Root]-[Chemical Class Suffix]

Key Formatting Rules:

 * Cation First: The more electropositive element always precedes the electronegative element.

 * Hyphenation: Hyphens strictly bind numerical prefixes and oxidation states to their core elemental roots. A single space separates the cation block from the anion block.

 * Zero State: Elemental molecules (e.g., N₂) use -Ø for their oxidation state.

 * Formal vs. Common: The full syntactic sequence is mandatory for formal academic literature and structural databases. Common spoken language rapidly compresses these components, dropping obvious valencies.

Polyatomic groups function as unified electronegative blocks. They use the suffixes -at (higher internal oxidation state) and -it (lower internal oxidation state).

Polyatomic Cation

Acid Morphology

Acids are constructed by appending the suffix -āc (derived from Latin acidum) to the parent polyatomic root, treating the hydrogen cation as implied by the acid classification.

 * Sulfuric Acid (H₂SO₄): Sūvat-āc

 * Sulfurous Acid (H₂SO₃): Sūvit-āc

 * Nitric Acid (HNO₃): Nidrat-āc

 * Carbonic Acid (H₂CO₃): Garvat-āc

 * Hydrochloric Acid (HCl(aq)): Hāral-āc (Formed from the halide base)

V. Organic Nomenclature Principles

Organic chemistry retains a limited, specialized morphology to prevent the system from becoming unwieldy, focusing on carbon chain lengths and functional groups.

Core Alkane Roots (Based on Stoichiometric Prefixes + -an):

 * C1 (Methane): Ekan

 * C2 (Ethane): Duan

 * C3 (Propane): Tiran

 * C4 (Butane): Katan

Functional Groups:

 * Alcohols (-OH): Append -ōl (e.g., Duanōl for Ethanol)

 * Organic Acids (-COOH): Append -ovāc (e.g., Ekanovāc for Formic Acid, Duanovāc for Acetic Acid)

 * Carbonyls (C=O): Append -ōn (e.g., Tiranōn for Acetone/Propanone)
